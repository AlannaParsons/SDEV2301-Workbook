Section 2 — Void vs Return (Slides 7–8)
    Which version is better for reuse? Why? (1–2 sentences)

    static void Add(int a, int b)
    {
        Console.WriteLine(a + b);
    }
    static int Add(int a, int b)
    {
        return a + b;
    }
    Answer:
        Void methods are not as good because they return nothing

Section 4 — Pass-By-Value (Slides 12)
    Predict the output:

    static void Change(int num)
    {
        num = 100;
    }

    int value = 20;
    Change(value);
    Console.WriteLine(value);
    Output: 20
        
    Explain why:
        Because local variables only exist inside the method and are destroyed when the method finishes
